# Sales-Dashboard-Using-Microsoft-Excel
📊 **Sales Performance Dashboard using Microsoft Excel**

I’m excited to share my **Sales Dashboard project built using Microsoft Excel!**

This interactive dashboard transforms raw sales data into meaningful business insights, helping analyze sales performance and track key business metrics.

**🔍 Key Features:**
- **Sales by Category:** Analyze revenue generated across different product categories.
- **Customer Count:** Track the total number of customers.
- **Profit Over Time:** Monitor profit trends and business growth over time.
- **Top 5 Profitable Customers:** Identify the top 5 customers contributing the highest profits.
- **Monthly Sales Analysis:** Track monthly sales performance and identify trends.
- **Interactive Slicers:** Two dynamic slicers (Year and Category) to filter and explore the data interactively.

**🛠️ Tools & Skills Used:**
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Formulas
- Slicers & Interactive Filters
- Data Cleaning and Data Visualization
- Dashboard Design

**🎯 Project Objective:**

To transform raw sales data into an interactive dashboard that provides clear insights into sales trends, customer contributions, category performance, and profitability, supporting better data-driven business decisions.

This project helped me strengthen my skills in Excel, data analysis, data visualization, and dashboard development.
